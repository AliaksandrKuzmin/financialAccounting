# FinancialAccounting  
Консольное Java‑приложение с многослойной архитектурой для учета доходов и расходов.  
Проект предназначен для фиксации финансовых операций, поиска данных по различным критериям и расчета итогового баланса.

---

## 1. Предметная область

Приложение позволяет регистрировать финансовые записи двух типов:

- **INCOME** — доход  
- **EXPENSE** — расход  

Каждая запись содержит:

**Сущность FinancialRecord:**
- **id** — уникальный числовой идентификатор (назначается автоматически).
- **type** — тип записи (RecordType: INCOME или EXPENSE).
- **category** — категория операции (например: Salary, Food, Transport).
- **amount** — сумма операции (положительное число).
- **description** — текстовое описание.
- **date** — дата создания записи (назначается автоматически).

---

## 2. Архитектура приложения

Приложение построено в соответствии с принципами многослойной архитектуры (**Layered Architecture**):

**Main → Controller → Commands → Logic (Service) → DAO → financial_records.txt**

Слои слабо связаны между собой и взаимодействуют через интерфейсы и централизованные провайдеры (**Singleton‑providers**):

- **entity** — модели предметной области (**FinancialRecord**, **RecordType**).
- **dao / dao.impl** — слой доступа к данным (**FinancialRecordDao**, **FileFinancialRecordDao**, **DaoProvider**).  
  Отвечает за чтение, запись и обновление файла. Оборачивает **IOException** в **DaoException**.
- **logic / logic.impl** — слой бизнес‑логики (**RecordLogic**, **RecordLogicImpl**).  
  Отвечает за создание записей, фильтрацию, поиск и расчет баланса. Оборачивает **DaoException** в **LogicException**.
- **controller / controller.impl** — слой контроллера и команд (**Controller**, **Command**, набор команд).  
  Реализует паттерн «Команда». Разбирает параметры, вызывает логику и формирует текстовые ответы.
- **main** — точка входа (**ConsoleUI**).

---

## 3. Формат хранения данных

Все данные сохраняются в текстовом файле **financial_records.txt** в корневой папке проекта.

- Каждая запись хранится на одной строке.
- Поля разделяются символом `;`.
- Порядок полей:
   id;type;category;amount;description;date;
- Пример строки:
  1;EXPENSE;Food;15;Lunch;2026-09-14
  
---

## 4. Список поддерживаемых команд

### **Добавление записи**
- **addIncome** — добавить доход  
- **addExpense** — добавить расход  

### **Обновление и удаление**
- **update** — обновить запись  
- **delete** — удалить запись  

### **Поиск**
- **findByDate** — поиск по дате  
- **findByCategory** — поиск по категории  
- **showPeriod** — показать записи за период  

### **Просмотр**
- **showAll** — показать все записи  
- **showBalance** — показать итоговый баланс  

---

## 5. Примеры текстовых запросов

Каждый запрос состоит из имени команды и параметров в формате `key=value`.

### Добавление расхода:
addExpense
category=Food
amount=15
description=Lunch

### Добавление дохода:
addIncome
category=Salary
amount=2500
description=Monthly payment

### Поиск по категории:
findByCategory
category=Food

### Баланс:
showBalance

## 6. Инструкция по запуску

### Требования:
- Установленный JDK 17+  
- IntelliJ IDEA (рекомендуется)  
- Внешние библиотеки не требуются (чистый Java SE)

### Запуск через IDE:
1. Клонируйте репозиторий или импортируйте проект как существующий Java‑проект.
2. Убедитесь, что в настройках проекта выбран JDK 17+.
3. Откройте класс:
   src/main/ConsoleUI.java
4. Запустите метод `main()` (Ctrl + Shift + F10 в IntelliJ IDEA).
5. Вводите команды в консоль.
